# A股罗盘与滚动罗盘分析方法

本文件同步记录运行时技能采用的分析规范，供 GitHub 审计、评审和后续实现使用。运行时来源：`a-share-compass-cron-stage` 与 `rolling-compass-ops`。

研究结论保持只读影子模式；生产权重、仓位、正式信号和交易动作继续受现有规则与人工授权约束。

# A股罗盘决策分析增强

用于 08:30、11:30、14:30、22:00 四窗口分析。目标是把行情、候选池、模型状态、验证结果和操作纪律连接成可复核的决策链。研究结论保持只读；生产权重、仓位和正式动作仍由既有规则与人工授权决定。

## 分析顺序

### 1. 市场状态

先回答四个问题：

1. 指数和宽度处于上行、分化、退潮还是修复；
2. 主线行业的强度、扩散度和持续性；
3. 成交额、涨跌家数、涨停/跌停、北向或主力资金字段是否完整；
4. 当前窗口相对上一窗口发生了什么变化。

输出字段：

- `market_regime`：偏强 / 震荡 / 防御 / 退潮；
- `breadth_state`：扩散 / 集中 / 分化 / 修复；
- `data_as_of`、来源和缺失项；
- `change_from_previous_window`。

空 rows 表示未知。资金流、涨停数和宽度缺失时使用 `UNAVAILABLE`，保留上一可用结论并标明日期。

### 2. 热点与ETF映射

按“行业热度 → ETF承载 → 可执行性”分析：

- 热度：涨停数量、行业涨幅、成交额增量、持续天数；
- 承载：ETF纯度、规模、流动性、跟踪标的；
- 可执行性：距支撑/目标/防守线、当日涨幅、追高风险、建议仓位。

每个热点分为：

- 主线确认：强度和扩散同时成立；
- 主线集中：龙头强、行业扩散有限；
- 轮动候选：短期增强，持续性待确认；
- 退潮观察：强度和成交同步减弱。

热点排名属于市场证据。正式 plant/watch/harvest 仍由现有选择器和执行门禁产生。

### 3. 候选逐项解释

每只ETF必须回答：

- 为什么进入候选；
- 当前状态适合持有、回踩观察、风险降仓或退出；
- 哪个价格和条件触发动作；
- 哪条证据会推翻当前判断。

最少证据集：趋势分、风险分、价格与支撑/目标/防守线、量价状态、中观状态、候选池资格原因。可用时补充行业宽度、主力资金、估值或筹码侧证据。

### 4. 策略健康度

借鉴“策略有效期”思路，对当前规则输出只读健康状态：

- `ACTIVE`：近期方向、超额和回撤都在允许范围；
- `MIXED`：部分窗口有效，表现分化；
- `DECAYING`：近期效果持续弱于历史基线；
- `INSUFFICIENT`：样本未达到门槛；
- `UNAVAILABLE`：缺少可复算数据。

至少报告：样本数、D1/5D/20D方向表现、相对沪深300收益、最大回撤、最近窗口与长期窗口差异。指标必须来自持久化样本或可复算缓存。

策略健康评级只进入研究说明，不自动改选择器权重、plant/watch/harvest成员、仓位或交易动作。

### 5. 归因分析

对上一阶段表现拆成：

- 市场：沪深300或对应宽基贡献；
- 行业：主题/行业相对市场贡献；
- 选择：ETF相对行业基准贡献；
- 时机：信号价到执行价、收盘价的差异；
- 成本：费用和滑点；
- 执行：计划内动作与临时偏离。

无法精确拆分时逐项返回 `UNAVAILABLE`，说明缺少的字段。禁止用总收益反推各分项。

### 6. 同类比较

比较必须在同一资产类别和行业经济中进行：

- 同主题ETF比较规模、成交额、跟踪指数、趋势、波动和回撤；
- 个股与ETF分开；
- 宽基、行业、商品、跨境ETF分组；
- 同一日期、复权口径和交易时段。

输出“首选承载 / 次选承载 / 流动性备选”，并说明差异来源。

### 7. 行动结论

每个窗口用统一操盘台格式：

1. 当前结论；
2. 允许动作；
3. 允许价格或区间；
4. 建议仓位；
5. 最晚执行条件；
6. 失效线；
7. 证据更新时间；
8. 数据或样本状态。

08:30重计划，11:30看确认/反转，14:30强调15:00前可执行性，22:00做收盘归因和下一交易日计划。

## 验证和防误导

- 评分、概率、历史命中率、预期收益、交易动作使用独立字段；
- `score >= threshold`只能称为达到评分门槛；
- 样本少于门槛显示 `INSUFFICIENT`；
- MFE/MAE缺逐日高低价路径时显示 `UNAVAILABLE`；
- 回测必须披露复权、T+1、费用、滑点、涨跌停和成交限制；
- 多窗口或多代理一致属于研究共识，不等同于独立证据；
- 每项结论保留来源、日期、模型版本和计算口径。

## 完成标准

- 当前窗口与上一窗口变化清楚；
- 每个候选都有理由、动作条件和失效条件；
- 研究评级未修改生产规则；
- 缺失证据以 `UNAVAILABLE` 或 `STAGING BLOCKER` 表达；
- 收盘后保存可用于D1/5D/20D复核的信号身份和价格；
- 文章、JSON和仪表盘叙事一致。

# 滚动罗盘信号深度分析增强

用于 A股滚动罗盘的单标的、多标的、盘中和盘后分析。核心对象是独立的“标的 + 日期 + 方向 + 价格簇”，每个周期节点保留为证据，执行上合并近价同向节点。

## 五层分析

### 1. 信号层

从D1读取并冻结：

- symbol、name、trade_date；
- BUY/SELL、cycle_code；
- triggered_at、received_at；
- trigger_price、price_source；
- event_id、storage、delivery.state。

同标的、同交易日、同方向、价格差不超过1%的节点形成一个信号簇。报告首个节点、后续确认节点和累计次数。每个周期节点仍保留在证据表中。

### 2. 价格与技术层

以持久化信号价为锚，比较：

- 当日开高低收；
- 后续D1/3D/5D收盘；
- MA5/MA10/MA20；
- DIF、DEA、MACD柱变化；
- RSI6、RSI12；
- 量比、换手、成交额变化；
- 平均成本、获利盘、90%筹码集中度。

日线收盘提供环境，不能替换信号价。低RSI属于超卖证据，反转仍需价格、量能和动量共同确认。

### 3. “为什么涨跌”归因层

按证据强度排序：

1. 市场与行业：指数、行业宽度、主题强弱；
2. 资金与量价：成交放大/收缩、主力资金、突破或破位；
3. 技术结构：均线、MACD、RSI、前高前低；
4. 筹码结构：成本、获利盘和拥挤度；
5. 新闻事件：公告、政策、财报和行业事件。

每个原因标注：`observed`、`corroborated`或`hypothesis`。新闻与价格同步只构成相关证据，因果结论需要公告或多源佐证。

### 4. 策略有效期与信号质量层

为每个信号簇输出：

- 方向验证：confirmed / reclaimed / mixed / watch；
- 信号质量：strong / normal / weak / exhausted / overheated；
- 历史样本数；
- D1/3D/5D方向命中；
- 从信号价计算的收益、MFE、MAE；
- 对应窗口的基准收益；
- 同类信号在近期和长期窗口的差异。

样本独立性以“标的+日期+方向+价格簇”计算。相邻周期节点不能重复增加样本数。

MFE/MAE要求信号后逐日高低价路径；缺失时返回 `UNAVAILABLE`。

### 5. 操盘层

统一输出：

- 当前结论；
- 左侧观察区；
- 右侧确认区；
- 减仓/退出区；
- 失效条件；
- 下一根关键K线需要观察的量、价、动量条件。

多方簇重点检查追高与拥挤；空方簇重点检查破位延续与衰竭。多空交替时，以最新正式多方之后的空方轮次和收盘位置为基线。

## 影子规则

### 多方过热

满足以下全部条件时标记 `过热观察`：

- RSI6 >= 80；
- 信号价 >= MA20 × 1.15；
- 信号价 >= 平均成本 × 1.15；
- 获利盘 >= 90%。

量比低于1.2时增强追高风险。标签只影响研究解读和通知去重，不隐藏生产信号。

### 空方衰竭

满足以下全部条件时标记 `衰竭观察`：

- 信号价 <= MA20 × 0.85；
- MACD负柱较前一交易日收窄；
- RSI6较前一交易日回升；
- 量比 <= 1.1。

### 近价重复确认

- 同方向、同日、价格差<=1%：一个执行簇；
- 第一条负责推送；
- 后续节点显示累计确认；
- 240m继续使用“停止验证”；
- 新正式多方出现后，旧空方轮次退出当前操盘基线。

所有影子规则观察10–20个交易日后再评估生产化。保存raw signal、cluster_id、标签、D1/3D/5D结果和版本。

## 每日全市场报告

每个标的包含：

1. 精确节点与信号价；
2. 收盘验证；
3. 涨跌归因；
4. 支撑、压力和价格地图；
5. 买入确认条件；
6. 减仓/退出条件；
7. 3—4条证据；
8. 数据缺口和样本状态。

报告顶部按执行优先级排列：

- 立即风险处理；
- 次日确认机会；
- 继续观察；
- 数据或样本阻断。

## 模型与回测边界

- 准确率按预测窗口、方向和模型版本拆分；
- 同时报胜率、盈亏比、平均收益和最大回撤；
- 样本少时显示 `INSUFFICIENT`；
- 历史复盘明确日收盘近似或分钟真实价；
- 费用、滑点、涨跌停和T+1进入可交易回测；
- 最优过滤组合属于样本内结果，必须进入影子期复核；
- 研究评分不自动隐藏节点、改仓位或改交易动作。

## 完成标准

- D1、API和页面三层证据一致；
- 每个信号簇都有价格锚、收盘验证、原因和操作条件；
- 周期节点没有被当作独立样本重复计数；
- 新闻因果强度有标签；
- MFE/MAE和成本数据缺失时明确 `UNAVAILABLE`；
- 生产信号保持原样；
- 页面与报告保留数据时间、来源和模型版本。
